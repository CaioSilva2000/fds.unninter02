# Página Web – Fundamentos de HTML

Este projeto foi desenvolvido como parte de uma aula prática da faculdade de Engenharia de Software, com foco exclusivo no aprendizado e aplicação dos fundamentos de HTML.

O objetivo foi compreender a estrutura básica de uma página web, utilização correta de tags semânticas e organização do conteúdo, sem o uso de CSS ou JavaScript.

🔗 Acesse a página online:  
https://caiosilva2000.github.io/fds.unninter02/

## Objetivos do projeto
- Praticar a estrutura básica de páginas web
- Aplicar corretamente tags HTML
- Entender a semântica do HTML
- Desenvolver base sólida para estudos futuros em CSS e JavaScript

## Tecnologias utilizadas
- HTML5
- GitHub Pages

## Contexto acadêmico
Projeto desenvolvido durante aula prática na faculdade (Uninter), com foco em fundamentos de desenvolvimento web.
